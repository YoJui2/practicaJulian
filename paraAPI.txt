Unitarios
para test, moneypatch reemplaza el input, permitiendo cambiar temporalmente partes del programa, testeando revisiones human in loop
para test, MagickMock crea objetos falsos durante las pruebas. Permite simular una función, un servicio o una dependencia sin ejecutar su comportamiento real


Integracion
La fixture de `tests/conftest.py` configura:

- SQLite en memoria.
- `StaticPool` para compartir la misma base durante cada test.
- Tablas SQLAlchemy temporales.
- Override de la dependencia `get_db` de FastAPI.
- Limpieza de tablas y engine al finalizar cada test.

Se comprueba el flujo completo de la API:

- Crear una pregunta con `POST /questions`.
- Listar preguntas.
- Consultar una pregunta por ID.
- Obtener estadísticas generales.
- Filtrar por categoría categorizada.
- Obtener estadísticas de categorización automática y manual.


para validacion:
Se comprueba que la API responde `422` ante:

- Campos obligatorios ausentes.
- Pregunta o respuesta vacías.
- Tipos incorrectos.
- Categorías de más de 100 caracteres.
- Fuentes de más de 255 caracteres.

concepto: 
 test unitario: verifica funciones o metodos de forma aislada, detecta errores de logica antes de escalar

 test integracion:asegura la comunicacion entre APIs, Bd, etc, verificando que se comuniquen correctamente sin perdidas

 test validacion: confirma que el codigo sea "correcto" para el usuario y no solo que "corre"

 test data quality: verifica que no hayan datos nulos en columnas criticas, valida que los tipos de datos sean correctos

 como se genera options
Usa google/flan-t5-base para generar distractores según cada pregunta.
Compatible con transformers 5.15.1.
Genera varias respuestas y selecciona tres distintas.
Evita opciones genéricas como “todas las anteriores”.
Mantiene OPTIONS_MODEL para cambiar el modelo por variable de entorno.
