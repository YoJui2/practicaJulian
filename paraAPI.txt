Visitá en el navegador:

| URL | Qué hace |
|---|---|
| `http://localhost:8000` | Mensaje de bienvenida |
| `http://localhost:8000/docs` | Documentación interactiva (Swagger UI) |
| `http://localhost:8000/questions` | Primeras 10 preguntas (GET) |
| `POST http://localhost:8000/questions` | Crear pregunta nueva (body JSON en `/docs`) |
| `http://localhost:8000/questions?skip=10&limit=5` | Preguntas 11 a 15 |
| `http://localhost:8000/questions/1` | Pregunta con ID = 1 |
| `http://localhost:8000/questions/category/geografia` | Preguntas filtradas por categoría |
| `http://localhost:8000/stats` | Total de preguntas y cantidad por categoría |

Ver cuantas preguntas hay:

docker compose exec -T db psql -U admin -d questions_db -t -A -c "SELECT COUNT(*) FROM questions;"

Limpiar completamente la base de preguntas (tambien borra las categorizaciones y reinicia los IDs):

docker compose exec -T db psql -U admin -d questions_db -c "TRUNCATE TABLE categorizations, questions RESTART IDENTITY CASCADE;"

Conservar solo las primeras 20 preguntas sin seleccionar por ID:

docker compose exec -T db psql -U admin -d questions_db -c "BEGIN; CREATE TEMP TABLE questions_to_keep ON COMMIT DROP AS SELECT id FROM questions ORDER BY ctid LIMIT 20; DELETE FROM categorizations WHERE question_id NOT IN (SELECT id FROM questions_to_keep); DELETE FROM questions WHERE id NOT IN (SELECT id FROM questions_to_keep); COMMIT;"
