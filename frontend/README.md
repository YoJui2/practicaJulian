# Frontend de Preguntados

Aplicación React + TypeScript creada con Vite.

Desde la raíz del proyecto se puede instalar y ejecutar con:

```bat
instalar-frontend.bat
iniciar-juego.bat
```

Durante desarrollo, Vite sirve la aplicación en <http://localhost:5173> y consulta FastAPI en `http://localhost:8000`.

Comandos disponibles dentro de `frontend/`:

```bat
npm run dev
npm run quality
npm run build
npm test
npm run test:coverage
```
